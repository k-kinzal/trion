# Specification conformance audit

The audit used the package rooted at [spec/trion.trion](../../spec/trion.trion). It compared the sentence and extension tables with the reader, the exported A/G contracts with the documented responsibility rules, and the MMT proof reports with the rules for deciding obligations and issuing certificates.

| Specification | Discrepancy | Correction and regression evidence |
| --- | --- | --- |
| [Extension readings](../../spec/extensions.trion) and [shared assumptions](../../spec/composition.trion) | An `otherwise` branch negated its entire guard, including the state of its enclosing block. | Negate the trigger alone. The [MMT regression](../../crates/trion-cli/tests/mmt_form.rs) checks the two guards under one shared state. |
| [Extension readings](../../spec/extensions.trion) and [supported grounds](../../spec/grammar.trion) | Grounding removed a type or relation trigger from the sentence and kept its positive condition in both branches. | Reject this specific `otherwise` form. The [MMT regression](../../crates/trion-cli/tests/mmt_form.rs) checks the unsupported diagnostic and absence of an archive. |
| [Diagram expansion](../../spec/extensions.trion) | An expanded sentence from a declared diagram could omit an inherited condition. Frame rendering also used the same keyword for distinct state frames such as `While` and `Until`. | Render the resolved sentence in its scope, retaining the frame keywords. The [diagram regression](../../crates/trion-cli/tests/diagram_rules.rs) compares the contracts of a diagram and its reparsed expansion. |
| [Missing cases](../../spec/verification.trion) | Coverage combined independent tests of values. A guard excluding both `open` and `closed` appeared to cover both. | Evaluate the whole guard with each closed-domain value substituted. The [coverage regression](../../crates/trion-verification/tests/missing.rs) distinguishes conjunction and disjunction of the exclusions. |
| [One result per obligation and certificate reporting](../../spec/proof.trion) | Failure to create a certificate directory or write an SMT-LIB or MoXI file discarded the proof report, including unrelated results. | Record the format error alongside all verdicts and continue with the other formats and obligations. The [certificate regression](../../crates/trion-cli/tests/certificate.rs) exercises a blocked directory and a blocked file. |
| [Proof verdicts and tool output](../../spec/proof.trion) | The specification classified every obligation that was not proved as unproved, while the command distinguishes refutation from an open result. The tool specification also described a certificate for each result. | Specify the separate verdicts and certificate eligibility. The [result tests](../../crates/trion-cli/tests/verification_results.rs) exercise proved, refuted, and decision-limited obligations. |
| [Propositional evidence](../../spec/propositional/results.trion) | The general exclusion rule required undecided for every incomplete enumeration, while the MMT path can check a certificate independently. | Require a checked certificate or a complete reference scan for exclusion. The [analysis CLI tests](../../crates/trion-cli/tests/analysis_cli.rs) exercise the incomplete enumeration and checked certificate path. |
| [MMT evidence replay](../../spec/propositional/results.trion) | Replay accepted an edited reason, question count, or extra counterexample alongside an intact propositional record. | Match the reported reason and count to the rebuilt record and use its checked valuation as the counterexample. The [replay regression](../../crates/trion-cli/tests/analysis_cli.rs) exercises all three edits. |
| [Compatibility](../../spec/obligations.trion) | The definition required an assumption from an existing contract. The implementation allows an empty set of normative contracts when an admissible environment exists. | State the empty case explicitly in the specification and the [Lean model](../../formal/Trion/Document.lean). The theorem `compatible_empty` gives its exact condition. The [CLI regression](../../crates/trion-cli/tests/verification_results.rs) exercises both possible environment outcomes. |

Existing conformance evidence also covers [package loading](../../crates/trion-cli/tests/project.rs), [source and citation checks](../../crates/trion-cli/tests/sources.rs), [extension and contract vocabulary mappings](../../crates/trion-language/tests/pattern_ledger/contract_mapping.rs), [propositional interchange](../../tests/conformance/core.rs), and [propositional grammar and versioning](../../tests/grammar/propositional.rs). The [self-hosting tests](../../crates/trion-cli/tests/self_hosting.rs) exercise the specification package through both commands. The [trust boundary](trust-boundary.md) records the scope of the metatheory and the runtime checks.

## Verification

Git tree `314a0463ced67834df7aeb5df9e98c51f9053f98` identifies the audited working tree with `record/` omitted.

- `lake build` in `formal/` completed all 13 jobs.
- `trion . --out DIR`, `trioc prove DIR --json`, and `trioc replay REPORT --form DIR` converted the current specification, proved its 14 obligations, and replayed its archived propositional result. The independent MMT type-check test for the specification also passed.
- The completed Rust suites recorded 64 passing tests across propositional conformance, the grammar, architecture and fault injection, missing cases, verification results in the verification library, the proof CLI's propositional analysis, flow rules, and Alethe syntax. The Cargo test targets were built with `--locked --offline`. Logs are in `target/spec-audit-conformance.log`, `target/spec-audit-boundaries.log`, and `target/spec-audit-rust/`.
- Direct CLI checks confirmed the two MMT branch conditions, rejection of a grounded type trigger in `otherwise`, the two warnings for a closed-domain guard excluding two values, retention of verdicts when the certificate directory is blocked, and rejection of an edited propositional reason.
- The remaining CLI suites were stopped after extended process startup stalls on macOS. A sample placed a stalled test binary at `_dyld_start`. In particular, the full reruns of the diagram, certificate, MMT, and CLI verification-result suites remain open. The first diagram regression run exposed missing primitive declarations in the fixture. The corrected fixture compiled and the formal contract comparison had already passed in that run.
